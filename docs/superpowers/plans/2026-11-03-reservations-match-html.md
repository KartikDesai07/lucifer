## Review Focus

1. **A write while a day, All dates or a search is shown** (Seat, Cancel, Restore, a form save, a delete) → one PUT / POST / DELETE with today's body rules, one GET of the unfiltered key after it, the counts and the header line follow, the selection keeps the same booking (or takes the next first row after a delete), the toast names the right guest. Owned by Task 1 (`reservations-view` + hooks tests) and Task 3 (choice tests).
2. **The clock** — a tab left open past midnight shows the new day as "Today" (the day is held as "unset"), Late / Due now / "in 12 min" move with the minute tick, a past day never shows Late (B11, B12). Owned by Task 1 (`reservations-view` tests with fixed `nowMs`, a 23:59 → 00:01 case).
3. **Long words at 360 / 375 / 390 / 430 and 1024** — a 120-character unbroken name, a 24-character table name, a 205-character note, 40 guests → no sideways scroll, names and table names wrap (Q5, B10), the table row's sub-line ellipsizes, tiles and chips grow. 4. **The 1280 boundary while something is open** (a tablet turned, a window resized) with the detail, the form, the seat dialog or the cancel confirm up → one frame, no remount, the open layer stays the top layer (`frameInUse`), an auto-picked booking gives way below 1280 while a pressed one stays (B5), focus returns to the opener. Owned by Task 3 (choice + frame tests) and Task 4 (the form frame).
