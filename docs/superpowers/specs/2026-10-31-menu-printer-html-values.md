### 0.4 Screen state and defaults
Component state keys: `mView` ('items' | 'cats', default 'items'), `mF` ('all' | 'avail' | 'oos' | 'hidden' | 'popular' | 'archived', default 'all'), `mVeg` ('All' | 'Veg' | 'Non-veg'), `mCat` ('All' or a category name; read `s.mCat||'All'`), `mQ` (search text), `mSel` (selected item keys), `mFOpen` (phone filter wrap), `mEdit` (item editor object or null), `mCatEd` (category editor object or null), `cats` (the category array), `itemOv` / `extra` (item overrides / added items). ### 0.5 Rendering conventions (as U0 §0.2–§0.4, U4 §0.5, plus what these screens add)
- Interpolations are `<span class="sc-interp">` wrappers; in flex rows the binding and a literal beside it are separate flex items with the row gap between them.
- `line-height: normal` = 1.3 × font-size (U0 §0.3) except where a line-height is written (header title `1.2` → 18 px). Text heights measured here: 10.5px→14, 11px→14, 12px→16, 12.5px→17, 13px→17, 13.5px→18, 14px→18, 14.5px→19, 15px→19, 18px→23.
- **Borders written `1.5px` compute and draw as `1px`** in this Chrome (as U3/U4): the table checkbox, the empty box (dashed), the printer mode buttons. Other engines may draw 1.5 px.
- **Fonts (measured):** every text computes `font-family: Geist` with tabular figures and `-webkit-font-smoothing: antialiased` (global rules, U0 §1.4), **except the price** (table price cell, card price) which is **`Geist Mono`** (`font-family:'Geist Mono',ui-monospace,monospace`, 13.5px / 600 in the table, 12.5px / 600 in the card sub-line; the mini logo is Shrikhand). Weights used: 400, 500, 600, 700 (the "sold out" count chips, the filter-count badge, the printer step numbers).
- Buttons with no `font-size` compute 13.3333px and keep the UA padding `1px 6px` (checkbox buttons set `padding:0`, the toggles `padding:0`, the segmented / pill buttons set their own padding, the editor Cancel / Save keep `1px 6px` with a fixed height).
- **Static hover strings become generated classes** (measured rule text, state `default` + `scp`): `.scp4:hover{background:var(--hover) !important}` (rail row, table row, categories row, printer ✕ etc.), `.scp3:hover{background:var(--accent-h) !important}` (Add / Save / Done / Connect), `.scpe:hover{background:var(--surface-3) !important}` (row edit, category arrows / edit), `.scph:hover{background:rgba(255,255,255,.1) !important}` (bulk-bar buttons), `.scp9:hover{background:var(--bad-t) !important}` (delete / remove size / Archive item / Remove the printing device). The exact class → element table is in each section.
- The global `button` transition list and `button:not(:disabled):active{transform:scale(.97)}` (U0 §1.4) apply to every button here (toggles, rows' name buttons, editor buttons included). The toggle tracks add `transition:background .15s` and knobs `transition:left .15s` (the printer panel's toggles `.2s`).
- **No `aria-*` or `role`**; `title` only where written. There is no designed focus style: see 9.5 and 21.
- Dark values are tokens only (U0 §1.1) except the literals: the checkbox tick `#FFFFFF`, toggle knobs `#FFFFFF`, the mini logo `#FFFFFF`, the printer status circle glyph `#FFFFFF`, the connect spinner `rgba(255,255,255,.4)` / `#FFFFFF`. Section 15 lists the visible dark differences.

## 22. View-model logic, read from `app.js` (written plainly; "measured" where a state confirmed it)

### 22.1 Menu items and counts
- `allItems()` = the seed `ITEMS` (each `{name, cat, veg, sizes:[[label, price]…], pop, oos}`; key = name) with `itemOv[name]` patches merged in, plus `extra` (items added in this session, `isNew:true`, key `'x'+Date.now()`). `live` = items not archived. Sizes of a one-price item are `[['Standard', price]]`.
- Listed items = `ok(item)` over **all** items, sorted by the category order in `cats` (stable): `ok = filterOK && (cat is All or item.cat === cat) && (veg is All or (Veg ? item.veg : !item.veg)) && (query empty or name or category contains the query, lower-case)`. `filterOK`: `archived` → archived items only; every other filter → **not archived** and: `all` any; `avail` not sold out; `oos` sold out; `hidden` `qr === false`; `popular` pop; `new` isNew (no UI uses `new`). Measured seed counts: Veg 50 and Non-veg 21 of 71 (`veg-veg`, `veg-phone-open`), Popular 13, sold out 1, hidden 0, archived 0.
- Counts: rail count = live items of the category; rail sold-out chip = live sold-out items of the category; All items = live; select options use the same live counts; "Archived (n)" counts archived items. Title count `list.length` + filter suffix (4.6). Header sub: live count, `cats.length`, live sold-out count (omitted when 0).
- Sort / order: only the category order; items inside a category keep their seed order (new items come last in their category; an item moved to another category goes to the end of that category's group in `allItems()` order).
- Price text: min / max of the sizes' prices: equal → `₹n`, else `₹min–max` (en dash, one ₹). Sizes text: more than one size → the labels joined by " · "; one size named Standard → "Single price"; one other name → that name. Card sub: `{category}` + ` · {n} sizes` when n > 1.
- Stock / QR toggles, bulk actions and archive all go through `patchItem` (an added item patches its `extra` entry, a seed item its `itemOv` entry). Undo restores the whole `itemOv` and `extra` objects taken before the action (so an undone bulk action also undoes nothing else).

### 22.2 Item editor (`mEdit`)
- `openEd(item)`: `{key, isNew: item.isNew, orig: item.name, name, cat, veg, multi: sizes.length > 1 || sizes[0][0] !== 'Standard', price: single size's price (string) or '', sizes: [[label ('' for Standard), price string]…], pop, oos, qr: qr !== false, archived, tried:false}`. Add: `{key:null, isNew:true, orig:null, name:'', cat: picked category or first, veg:true, multi:false, price:'', sizes:[['Regular',''],['Large','']], pop:false, oos:false, qr:true, archived:false, tried:false}`.
- Price typing: `String(value).replace(/\D/g,'').slice(0,5)`. Size name typing: raw. `sizes` rows can be added without limit; removed only while more than 2 remain.
- `mCheck` (9.3) is evaluated on every render; errors are shown only when `tried`. `mSave`: if any error → `tried:true`, nothing else. Otherwise: name trimmed and inner spaces collapsed; sizes = single → `[['Standard', +price]]`, multi → rows with a name → `[[name.trim(), +price]]` (a row with a price but no name was already rejected by `mCheck`); the Manager applies at once (`extra` push with `isNew:true` for a new item, `patchItem` for an edit) + toast "{name} added to {cat}" / "{name} updated" with Undo; any other role calls `ask()` → the approval dialog with sub "Add {name}" / "Save changes to {name}" and done toast "Menu updated" (the change is applied only after the PIN).
- `saveItem()` (an older function, 421–430, not wired to the current editor) is dead code with other words ("is already on the menu", "Every size needs a price"): **not rendered anywhere** (measured: the live editor uses `mCheck` / `mSave`).
- Toggles: `oos` (inverted), `qr`, `pop` flip their flag in `mEdit`; they take effect only on Save (unlike the list toggles).
- Archive / Restore: `patchItem(archived: !archived)`, `mEdit:null`, toast "{name} archived · hidden everywhere" / "{name} restored" (restore text only when the item was archived). Archived items disappear from every filter except Archived, from the rail counts, the select counts and the header sub; they still block a duplicate name.

### 22.3 Category editor and Categories view
- Open: edit `{orig:name, name, sec, station, kot, err:''}`; add `{orig:null, name:'', sec:'Mains', station:'Kitchen', kot:true, err:''}`. Any change clears `err`.
- `catSave`: name trimmed + collapsed; < 2 chars → err "Enter a category name"; case-insensitive duplicate of another category → "This category already exists". Edit: replaces the entry in place (order kept), renames the category on all items (`patchItem(cat)`), updates `mCat` if it was the picked category, toast "{name} saved" + Undo (restores `cats`, `itemOv`, `extra`). Add: appended at the end of `cats` (shown last in its section group), toast "{name} added · add items to it from Items" + Undo (restores `cats`).
- Rows grouped by `SECTIONS` order; inside a section by array order; arrows swap two entries of the array that are neighbours **within the same section** (first / last disabled); no toast, no undo; the order is shared by the Items view (sort), New Order and the QR menu.
- Delete: blocked when the category has any item (archived included) → toast; else removed + toast "{name} deleted" + Undo.
- Opening a category from its row: `mView:'items', mCat:name, mF:'all', mQ:''` (the Veg control and selection are left as they were except `mSel` is not cleared).

### 22.4 Printer (`prVals`, defaults `{open:false, mode:'counter', dev:null, busy:false, searching:false, found:null, more:false, paper:'80', kot:true, bill:true, logo:true}`)
- `here = mode === 'here'`; `on = !here || !!dev`. Status card, dot colour and button title follow `on` (15, 17). Device section opacity `here ? 1 : .6`; sub text by `here`; `connected = !!dev`, so the connected row replaces the connect / steps / search blocks in **either** mode; `warnD = here ? block : none` (the warn line shows only for This device, only while not connected); `testD = on ? flex : none`.
- `pick(dev)`: `busy:true`, clears any pending timer, after **1200 ms** sets `{busy:false, dev, mode:'here', found:null}` and the toast "Connected to {name}" (so picking a printer while in Counter mode switches the mode to This device). `connect()` ignores clicks while busy and picks `{name:'TVS RP3160 Gold', meta:'USB'}`; the label is "Connecting…" while busy, opacity .75, spinner shown.
- `search()`: ignored while searching; `searching:true, found:null`; after **1400 ms** `found` = [`Epson TM-T82X` / `Wi-Fi · 192.168.1.42`, `Kitchen printer` / `Network · 192.168.1.57`] (`meta` strings as shown); label "Searching…". The found rows' Use calls `pick`.
- `disconnect()`: `dev:null` + "Printer disconnected". `remove()`: `dev:null, mode:'counter', more:false` + "Printing device removed · each device prints its own slips". `test()`: "Test slip sent to {dev.name}" (This device) / "… Counter PC".
- `modes`: Counter PC / This device (labels and subs in 18); `papers` 58 / 80 (`P.paper` string; device meta `{meta} · {paper} mm paper`); the three toggles flip `kot` / `bill` / `logo` (default true; track `var(--accent)` on, `var(--border)` off, knob `18px` / `2px`). `more` toggles the options (chevron 180° / 0°). `close` / scrim click → `open:false`; the Done button is the same `close`. State persists across routes (the object is in the component). Timers are not cancelled when the panel closes (a connect started and then dismissed still completes and flashes its toast).
- The toast text "Connected to …" appears under / over the open panel at the shell position (z 70 above the z 60 panel).

### 22.5 Nav / shell facts used
`nav(r)` sets `route` and closes the cart and the More sheet; **it does not touch `mView`, `mF`, `mCat`, `mQ`, `mSel`, `mFOpen`, `pr`**. `Escape` clears `mEdit` (item editor), the context menu, table picker, order panels, modal, cash, cart, category sheet, More sheet and confirm — **not** `mCatEd`, **not** `pr`, **not** the approval dialog (that has its own Escape handling when open).

## 23. HTML bugs and oddities seen (listed, not "fixed")
1. **Table overflows at t820 (All categories)**: `tbl` is chosen at `listW >= 700` (formula `cw − 40` = 704) but the real inner width is 666 and the columns need 708 (18 + 200 + 120 + 110 + 72 + 72 + 32 + 6 gaps of 14); the grid overflows by 42 px and the list's `overflow:clip` hides 27 of the 32 px of the edit button (`r0.edit [791,253,32,32]` vs list right edge 796). With a category picked (no Category column) it fits. Also the head row's last cell; the name column is at its 200 px minimum.
2. **Category rail rows are 22.4 px, not 36**, because they shrink in the column-flex rail (3).
3. **Phone category chips collapse to 0 px** whenever the list is long (4.5): invisible, but their buttons are still in the tab order and `clickJs` on them lands on the content below (measured `chip-pick` before the fix: nothing happened).
4. **Item name collapses to 0 with four or more badges** (`flex:none` badges, name is the only shrinkable item) — a row with Popular + New + Sold out + Hidden on QR shows no name; with two badges the name keeps 12 px ("T…") (5.2).
5. **Phone cards lack bulk selection, the QR toggle and the edit button** (6): QR visibility and multi-select cannot be changed from the phone layout; the bulk bar and the select-all box exist only in the table layout.
6. **No printer button in the Menu header** (and none on Reservations) although the panel is app-wide.
7. **Grammar**: bulk toasts say "1 items marked sold out / back in stock / hidden from QR menu / shown on QR menu"; the header sub and counts handle singular ("1 item") but the bulk bar writes "1 item selected" and the toasts do not; the Categories meta writes "1 item".
8. **Escape closes the item editor but not the category editor or the printer panel** (22.5).
9. **Role leaks**: a Cashier can toggle stock / QR, run every bulk action, archive / restore, add / edit / reorder / delete categories without a PIN; only the item editor's **Save** asks a manager's PIN (and says so in a note). The editor's own toggles (In stock / QR / Popular) are applied only on Save.
10. **Duplicate-name check ignores archived state** and the `New` filter has no UI; "Archived" items cannot be searched unless the Archived filter is on.
11. **Selection survives hidden rows**: searching or toggling Veg after ticking rows keeps the hidden rows selected and counted by the bar; select-all / "–" marks reflect only the listed items.
12. **Sticky table head sticks 20 px below the header** (it respects the column's top padding), so rows scroll visibly through that strip above it.
13. **Duplicate style keys**: the printer panel's Test print and the result "Use" buttons write `height`, `padding`, `font-size` twice; the later pair wins (32 / 11 / 12.5 and 30 / 11 / 12.5). `borders:1.5px` compute as 1px here (select-all, mode buttons, radio, empty box).
14. **`color-mix(in oklab, …)` borders** (status card, Remove button) compute to `oklab()` colours; plain `rgba` equivalents: ok 30 % = `rgba(36,161,72,.3)`, warn 35 % = `rgba(255,131,43,.35)`, bad 40 % = `rgba(218,30,40,.4)` (approximate: the mix is in oklab, not sRGB).
15. **Dark theme**: the bulk bar is `var(--ink)` = near-white (`rgb(244,244,245)`) in dark, but its button borders and hover wash are `rgba(255,255,255,…)` (invisible on it). The unselected checkbox in dark is `rgb(23,23,26)` with `rgb(46,46,51)` border. Everything else is tokens.
16. **Contrast (computed)**: the white glyph in the printer status circle is 3.35:1 on `var(--ok)` green and **2.46:1** on `var(--warn)` orange; `warn-i` on `warn-t` 4.58; `bill-i` on `bill-t` 4.52; `ok-i` on `ok-t` 4.55; `text-3` on white 5.28 (10.5 px "In stock" label), on `surface-2` 5.05; dark `text-3` on `surface` 4.58.
17. **Printer panel**: Esc does not close it; "Printing is on" is shown for Counter PC regardless of any real printer; the device section stays clickable at `.6` opacity in Counter mode; picking a printer while in Counter mode silently switches the mode to This device; timers survive closing the panel; the footer's `env(safe-area-inset-bottom)` is the only inset handling (Chrome 0).
18. **Category delete**: the blocked toast counts archived items and says "move them to another category first" while the button's tooltip says "Move or archive its items first" (archived items also block).
19. **Editor**: a seed item with exactly one non-"Standard" size (none in the seed) would open in Sizes mode with one row and could not be saved; the single-price red border colours a box that is hidden in Sizes mode (only the text shows); the editor never sets `aria-*` / labels (`for`/`id`).
20. **Rail "All items" chip counts sold-out items; the Archived filter has no rail counterpart**, and the Pizza chip text in the phone strip shows no counts (only "All 71").
