## 19. View-model logic, read from `app.js` (written plainly; "measured" where a state confirmed it)

### 19.1 Days, counts, the list
- `today = dkey(now)` (local `YYYY-MM-DD`); `day = rsDay || today`; `dayList` = bookings whose local date is `day`. `ACT` = booked + confirmed. **`isLate(r)` = ACT and now > time + 15 min** (Ananya 9:00 PM → late at 9:30).
- Select counts `cnt(k)` over `dayList`: `upcoming` = ACT (late ones included), `seated`, `done`, `noshow`, `cancelled`, `all` = every status. Header sub: ACT count of the day (singular "booking" at 1) + their guests + `fullDay` ("Monday, 19 October").
- Listed rows: **not searching** → `dayList` filtered by the tab, sorted by time; **searching** (trimmed, lower-cased query non-empty) → every booking on every date where `name + ' ' + table + ' ' + 'T'+n` contains the query, **or** the query's digits (≥ 3 of them) are in the phone; sorted by distance from now (`|time − now|`, nearest first: Simran Kaur today 7:45 PM before Fri 23 Oct 8:00 PM). The tab is ignored while searching.
- `flat` = the rows of `slotsG` in order (half-hour slots, or days when searching); each row gets `bt` (`0` for the first, `1px solid var(--border-2)` after), `timeFull` "9:00 PM", `cardSub` "{g} guests · {T3 | No table}", `line2` = sub + tags (", ") + note joined by " · ", and **`icons` = the action icons without Edit, first two only**.

### 19.2 Relative time `relOf(r)` (card line 3 / table time cell / detail banner)
`m = round((time − now) / 60 000)`. Seated → **"Seated {hm(seatedAt or time)}"** `var(--ok-i)` 500. Not booked / confirmed → "" (done / no-show / cancelled). `m < −15` → **"Late · {dur}"** `var(--bad-i)` 600 ("Late · 30 min"). `m ≤ 0` → **"Due now"** `var(--warn-i)` 600. `m ≤ 60` → **"in {m} min"** `var(--accent-i)` 600 ("in 15 min", "in 45 min"). Same day → **"in {dur}"** `var(--text-3)` 400 ("in 1h 30m"). Another day → "". `dur(ms)`: `m = max(1, round(ms/60 000))`; `< 60` → "{m} min", else "{h}h {mm}m" (two-digit minutes: "1h 30m", "2h 05m"). `hm()` = "9:00 PM" (no leading zero, AM / PM).

Otherwise: create a Dine-in order for the table (or update its guests / customer), set the booking `seated`, `table`, `seatedAt = now`, close the dialog, toast **"{first} seated at T{n} · {g} guests"** + Undo (restores bookings **and** orders). It does not navigate to the order.
- Assign (table cell "Assign" / detail "+ Assign a table", shown for active or seated bookings with no table): today → the dialog in assign mode; **another day → the edit form** (measured `assign-other-day`).
- Dialog tiles (`rspVals`), per table: `o` = an open order with items; `cf = rsConflict(id, table, time)`; `fit = seats ≥ guests`; **`off = o && !assignOnly`** (an occupied table is disabled for seating but pickable for assigning). Sub: o → "Occupied · ₹{total}" (₹ + `en-IN` grouping), cf → "Seated · {first}" / "Booked {9:45 PM}", fit → "{s} seats", else "Seats {s} only"; sub colour `var(--warn-i)` for o / cf / not fit, else `var(--ok-i)`; dot `var(--info)` / `var(--res)` / `var(--ok)` / `var(--warn)`; border `var(--ok)` only when fit and free and no conflict. A conflicting or too-small table can still be picked. Assign pick → `table` set, toast "T{n} assigned to {first}" + Undo, dialog closed.
- **`rsConflict(id, table, time)`** = another booking on the same table, the same date, status booked / confirmed / seated, less than **`RHOLD` = 90 min** apart (either side).

### 19.6 The form (`rsNew` / `rsEdit` / `rfVals` / `rfCheck` / `rfSave`)
- New: `{name:'', phone:'', day: rsDay if the route is Reservations and rsDay ≥ today else today, time:null, guests:2, table:null, tags:[], note:'', source:'Phone', remind:true, tried:false}` + the prefill (Book again). Edit: the booking's values, `time` "HH:MM", **`remind:false`**, its `status` (kept on save: editing never changes the status).
- Phone typing: digits only; a leading "91" is dropped when more than 10 digits; cut to 10. At 10 digits, a known customer or an earlier booking with that phone **fills the name if the name is empty**. Guest info `gi` (10 digits only): customer or ≥ 1 completed / seated visit → "Returning guest" + " · {visits} visits · last {last}" (customers only) + " · {n} no-show(s) before"; else no-shows → "Heads up · {n} no-show(s) on this number"; else "New guest · a customer profile is created on arrival". Colours: `var(--accent-t)` / `var(--accent-i)`; any no-show → `var(--warn-t)` / `var(--warn-i)`; a new guest → `var(--surface-2)` / `var(--text-2)`.
- Guests 1 … 40 (− / +); quick 2 / 4 / 6 / 8 / 10; hint "Large party · consider joining tables" at ≥ 8.
- Days: 7 chips from today (top "Today" / "Tmrw" / weekday short, num = date); "More" = a native date input (`min` = today); a day outside the 7 → the More chip reads "30 Oct" on `var(--accent-t)`.
- Slots: Lunch 12:00–3:30 (8), Dinner 6:00–10:30 (10), every 30 min. `off` = slot < now − 10 min (today at 9:30 PM: every slot up to 9:00 is off, 9:30 on). Load: guests of the day's other booked / confirmed / seated bookings less than 45 min from the slot; level 1 (> 0), 2 (≥ 8), 3 (≥ 16) → that many dots in `var(--ok)` / `var(--warn)` / `var(--bad)` (white on the picked slot; the rest `var(--border)` / `rgba(255,255,255,.25)`); title "Already passed" / "{n} guests booked around this time" / "Quiet".
- Tables: for each table `cf` (conflict at the chosen time), `o` (open order, only when the day is today and the time is < 90 min away), `fit`; **score = (cf ? 1000 : 0) + (o ? 500 : 0) + (fit ? seats − guests : 200 + guests − seats)**. "Best fits for {g} guests" = tables with no cf, no o and fit, sorted by score then number, **first 7**, the selected one prepended if missing; "Show all tables" = all 22 in `TABLES` order. Chip sub: cf → "Seated · {first}" / "Booked {hm}", o → "Occupied now", fit → "{area} · {s} seats", else "Seats {s} only"; `op .7` for cf / o (not when picked). Click toggles the table. The "Unassigned · Choose at arrival" chip clears it.
- Table message `tMsg`: after Save with a table error, or whenever the picked table conflicts → the red sentence **"T3 is already booked at 9:45 PM for Rahul Mehta. Pick another table or leave it unassigned."** / **"T4 has Neha Joshi seated from 9:00 PM. Pick another table or leave it unassigned."** (`var(--bad-t)` / `var(--bad-i)`); picked table occupied → **"T7 is occupied right now. It may not be free by 10:00 PM."**; picked table too small → **"T3 seats 4. For 8 guests you may need to join a table."** (both `var(--warn-t)` / `var(--warn-i)`).
- **`rfCheck`**: name blank → "Add the guest’s name"; phone not 10 digits → "Enter a 10-digit mobile number"; no time → "Choose a time"; time < now − 10 min → "This time has already passed"; table conflict → the sentence above. Shown only after a Save attempt (`tried`), except the table sentence. Summary line: "{Mon, 19 Oct} · {9:30 PM | time not set} · {g} guests · {T3 | no table}", after a failed Save **"Fix the highlighted fields to continue"** (`var(--bad-i)`).
- **`rfSave`**: blocked → `tried:true` only. Else name trimmed and each word capitalised (`\b\w` → upper: "asha verma" → "Asha Verma"), note trimmed, customer linked by phone. Edit → replace, close, toast **"Booking updated · {Mon, 19 Oct}, {9:45 PM}"** + Undo. New → append `status:'booked'`, close, **show that day** (`rsDay`), tab Upcoming, search cleared, toast **"Booked · {Mon, 19 Oct}, {10:00 PM} · {g} guests"** + **" · confirmation sent on WhatsApp"** when the switch is on, + Undo. Delete (edit only) → removed at once, toast "Reservation deleted" + Undo, **no confirmation**.

## 20. HTML bugs and oddities seen (listed, not "fixed")
1. **Most of `rsVals()` is never rendered** (§5): no day strip, no status pills, no Up next, no stats, no pacing chart, no List / Timeline switch, no timeline (`isTl:false`), no floor-at-time (`showFloor:false`), no group heads; the slot chip is in the markup but cannot be reached. 3. **Native pickers** (the owner's rule forbids them in our app): the day label's transparent `input type="date"`, the form's "More" `input type="date"`, and the status filter is a native `<select>`.

7. **The dock can never be closed** (no ✕ at ≥ 1024) and auto-selects the first row on every list change; "No booking selected" appears only on an empty list.
